# Test Case Excel 交付物

本目录保存基于已确认需求单单独编写的 Test Case Excel。

## 内容边界

- Test Case 不是需求单正文的一部分。
- 需求单负责描述业务变更、判断条件、处理动作、输出结果和异常边界。
- Test Case 在需求单业务口径确认后单独生成。
- 正式交付格式为 `.xlsx`；Markdown 只可作为临时分析或字段映射，不作为最终交付。
- Excel 文件必须记录其依据的需求单名称和版本。

建议命名：

```text
项目名_TestCase_vX.Y.xlsx
```
