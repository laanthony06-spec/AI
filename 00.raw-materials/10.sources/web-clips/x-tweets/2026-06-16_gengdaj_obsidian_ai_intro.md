## 核心观点

这篇文章主张在 AI 时代用 Obsidian 作为个人知识与内容工作台的底座。Obsidian 的价值不只是写笔记，而是作为本地 Markdown 仓库，承接网页剪藏、GitHub 备份、飞书协作、公众号发布、X 长文发布，以及 Codex / Claude Code 等 Agent 工具的协同。

## 关键方法

### 1. 本地优先

Obsidian 管理的是本地文件夹，不是某个平台账号里的数据。资料以 Markdown 文件保存，便于长期迁移、检索、备份和被 Agent 读取。

### 2. GitHub 备份

文章建议将 Obsidian vault 连接到 GitHub 私有仓库，并通过 Obsidian Git 插件进行自动 commit 和 sync。这样可以获得历史版本、云端备份和多设备恢复能力。

### 3. 图片资产跟随文章

使用 Custom Attachment Location 等插件，让图片按文章独立归档，避免文章移动或复制后图片路径断裂。

### 4. 内容工作台化

Obsidian 不只是笔记软件，还可以通过插件接入：

- Terminal
- Web Clipper
- Advanced Tables
- Excalidraw
- Git
- 飞书 CLI
- 公众号预览与草稿上传
- X Article 预览与草稿上传

### 5. 安全边界

文中特别强调：GitHub token、飞书凭证、公众号 AppID / AppSecret、X cookie / token 等敏感信息不要写入文章，也不要提交到 GitHub。
