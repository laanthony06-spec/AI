# 04_Case

> 脱敏案例库。每完成一个需求后，新增一个 Case。

## 命名规则

```text
Case001_简短脱敏名称.md
Case002_简短脱敏名称.md
```

## 每个 Case 必须包含

- 背景
- 为什么改
- 原逻辑
- 新逻辑
- 修改原因
- 容易遗漏
- Review 重点
- 上线注意事项
- 可复用经验

## 当前状态

- `Case_Template.md`：案例模板。
- `Case001` ~ `Case005`：Phase 1 占位案例，等待用户用脱敏历史案例替换。
- `Case_STNLoadingBalance_v0.1.md`：工作中案例，用于沉淀机台维度 Loading、Priority Loading、Report 唯一维度等经验。
