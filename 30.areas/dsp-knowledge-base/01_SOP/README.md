# 01_SOP

> DSP 文档与测试规范目录。写需求单、测试用例、流程图前先读本目录相关文件。

## 文件

- `Requirement_SOP.md`：需求申请单速查入口；完整规范统一维护在需求单工程。
- `TestCase_SOP.md`：Test Case 撰写规范。
- `FlowChart_SOP.md`：流程图撰写规范。

## 使用方式

- 写需求单：从 `Requirement_SOP.md` 进入完整 SOP，再读相关逻辑知识。
- 写测试用例：先读 `TestCase_SOP.md`，再读需求单和影响模块。
- 画流程图：先读 `FlowChart_SOP.md`，优先输出 Mermaid，正式 Word 交付时再转成图片。
