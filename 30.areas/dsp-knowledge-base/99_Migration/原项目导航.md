- `README.md`：DSP Workspace 总入口、建设阶段、使用方式。
- `AGENTS.md`：Codex 在本项目内的读取顺序、安全边界和输出规则。

## 核心目录

- `00_System\`：RTD、AMA、MES、MCS/AMHS、EAP 等系统边界知识。
- `01_SOP\`：需求单、测试用例、流程图的撰写规范。
- `02_Logic\`：Reason、Sorting、Pirun、Context、DispatchRules、QZone、NPW，以及具体功能/案例逻辑。
- `03_Template\`：需求单、测试用例、Review 模板。
- `04_Case\`：案例库；每个需求完成后新增一个 Case。
- `05_PromptLibrary\`：高频标准 Prompt；v1.1 已拆分为 Requirement / Review / TestCase / FlowChart / Risk 等独立 Prompt。
- `06_Workflow\`：从制造需求到 Requirement / TestCase / Review / Case 的工作流。
- `07_ReviewAssistant\`：Review 检查规则；v1.1 已拆分 RTD / AMA / Report / TestCase 等检查清单。
