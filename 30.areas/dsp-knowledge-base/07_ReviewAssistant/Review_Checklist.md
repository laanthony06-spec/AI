# Review Checklist

## SOP 符合性

- [ ] 是否有基础信息
- [ ] 是否有项目背景
- [ ] 是否有存在问题
- [ ] 是否有需求目标
- [ ] 是否有原逻辑 / 现逻辑 / 修改原因
- [ ] 是否有待确认事项

## 逻辑完整性

- [ ] 数据来源是否明确
- [ ] 字段是否明确
- [ ] 获取条件是否明确
- [ ] 判断逻辑是否明确
- [ ] 输出结果是否明确
- [ ] 异常处理是否明确

## RTD 影响

- [ ] 是否影响 Reason
- [ ] 是否影响 Sorting
- [ ] 是否影响 Dispatch
- [ ] 是否影响 Rule
- [ ] 是否影响 UI
- [ ] 是否影响 Report

## AMA 影响

- [ ] 是否说明执行频率
- [ ] 是否说明触发条件
- [ ] 是否说明数据获取
- [ ] 是否说明执行动作
- [ ] 是否说明输出结果

## 系统影响

- [ ] 是否影响 MES
- [ ] 是否影响 MCS
- [ ] 是否影响 EAP
- [ ] 是否影响上下游系统

## 测试完整性

- [ ] Normal Case
- [ ] Boundary Case
- [ ] Exception Case
- [ ] Recovery Case
- [ ] Regression Case

## 脱敏与待确认

- [ ] 是否移除敏感字段
- [ ] 未知字段是否写 `【待确认】`
- [ ] 是否存在未经确认的推断
