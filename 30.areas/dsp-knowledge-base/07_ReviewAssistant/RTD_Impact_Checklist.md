# RTD Impact Checklist

## Reason

- [ ] 是否新增 Reason。
- [ ] 是否修改既有 Reason。
- [ ] Reason 优先级是否明确。
- [ ] Reason 输出是否会影响制造理解。

## Sorting

- [ ] 是否新增排序字段。
- [ ] 排序方向是否明确。
- [ ] 多字段排序优先级是否明确。
- [ ] 空值排序位置是否明确。

## Dispatch / Where Next

- [ ] 是否影响派工候选 Lot。
- [ ] 是否影响候选机台。
- [ ] 是否影响跨厂 Transfer。
- [ ] 是否影响高优先级 Lot。

## Rule / UI / Report

- [ ] Rule 插入位置是否明确。
- [ ] UI 配置是否有默认值。
- [ ] Report 是否有唯一维度。
- [ ] Report 是否需要历史保留。
