# 07_ReviewAssistant

> DSP Review 助手。用于检查需求单、测试用例、Report、RTD / AMA 影响。

## 文件说明

| 文件 | 用途 |
| --- | --- |
| `Review_Checklist.md` | v0.1 总检查清单 |
| `Requirement_Review_Checklist.md` | 需求单完整性与可开发性检查 |
| `RTD_Impact_Checklist.md` | RTD Reason / Sorting / Dispatch 影响检查 |
| `AMA_Impact_Checklist.md` | AMA 执行频率 / 动作 / 异常检查 |
| `Report_DB_Checklist.md` | Report / DB 字段检查 |
| `TestCase_Review_Checklist.md` | 测试用例覆盖性检查 |

## 使用方法

真实需求 Review 时，至少读取：

```text
Requirement_Review_Checklist.md
RTD_Impact_Checklist.md
Report_DB_Checklist.md
```

若涉及 AMA，再读取：

```text
AMA_Impact_Checklist.md
```
