- [ ] 是否覆盖需求主流程。
- [ ] 是否覆盖每个判断条件。
- [ ] 是否覆盖新增字段。
- [ ] 是否覆盖 Report 输出。
- [ ] 是否覆盖 UI 配置。

## 类型

- [ ] Normal Case
- [ ] Boundary Case
- [ ] Exception Case
- [ ] Recovery Case
- [ ] Regression Case
