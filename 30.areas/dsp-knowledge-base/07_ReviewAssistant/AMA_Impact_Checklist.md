# AMA Impact Checklist

## 执行频率

- [ ] 是否说明 AMA 执行频率。
- [ ] 是否说明触发时机。
- [ ] 是否说明是否可重复执行。

## 数据获取

- [ ] 是否说明输入数据。
- [ ] 是否说明筛选条件。
- [ ] 是否说明跨厂资料如何处理。

## 执行动作

- [ ] 是否说明 Move / Transfer / Auto Split / 其他动作。
- [ ] 是否说明动作失败时处理。
- [ ] 是否说明与 MES / MCS / EAP 的交互。

## 异常与恢复

- [ ] Lot 状态变化后是否重算。
- [ ] 机台状态变化后是否重算。
- [ ] 搬送失败后是否恢复。
- [ ] 是否需要人工介入。
