# Report / DB Checklist

## Report

- [ ] Report 名称是否明确。
- [ ] 生成频率是否明确。
- [ ] 唯一维度是否明确。
- [ ] 字段列表是否完整。
- [ ] 字段含义是否明确。
- [ ] 字段来源是否明确。
- [ ] 空值或无资料时如何表示。

## DB / 字段

- [ ] 是否新增表。
- [ ] 是否新增字段。
- [ ] 是否修改字段口径。
- [ ] 是否影响历史数据。
- [ ] 是否需要补数。
- [ ] 是否需要清理旧数据。

## 验证

- [ ] 每个输出字段是否有 DB Validation。
- [ ] 是否可通过样例 Lot 验证。
- [ ] 是否可通过边界数据验证。
