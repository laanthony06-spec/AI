# Requirement Workflow v0.1

## 输入

用户提供：

- 背景
- 需求
- 限制
- 预期
- 涉及系统
- 已知字段
- 未知字段

## 流程

```text
读取 README / PROJECT_MAP
↓
读取相关 System / Logic
↓
读取 SOP / Template
↓
生成需求分析
↓
生成流程图
↓
生成 Requirement
↓
生成 Test Case
↓
生成 Review Checklist
↓
列出待确认事项
```

## 输出

- 需求分析
- 流程图
- 需求申请单
- 测试用例
- Review Checklist
- 待确认事项

## 时间目标

成熟后，目标是 5~10 分钟完成初稿。
