## 本项目的事实来源声明

- 新写需求可能是在修改 v0.5 或历史交付逻辑，新旧差异先作为变更候选。
- 评审时分别核对当前线上行为、本次需求声明、历史需求和原始证据。
- 只有完成冲突确认后，才能把某个版本标记为本次需求的确认基线。
- 当前文件名中的“最终版”沿用历史命名，不等于已经完成本次事实确认。
