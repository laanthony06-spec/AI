# 系统约定记忆

- Obsidian 是长期知识中枢。
- `00.raw-materials/10.sources/` 存放原始资料。
- `00.raw-materials/90.processed/` 存放加工后知识。

- Token 不在回答中回显。
- 涉及敏感资料时默认只做本地处理。

## Windows LibreOffice 调用约定

- 无界面转换优先调用 `C:\Program Files\LibreOffice\program\soffice.com`，不要调用可能不返回的 `soffice.exe`。
- 每次转换使用独立的 LibreOffice 配置目录，并将其转换为规范的 `file:///C:/...` URI；Python 中优先使用 `Path(profile_dir).resolve().as_uri()`。
- DOCX 转 PDF 的可靠形式为：`soffice.com --headless -env:UserInstallation=<file URI> --convert-to pdf --outdir <输出目录> <输入 DOCX>`。
- PDF 转 PNG 时，将 `C:\Users\温浩奇\.cache\codex-runtimes\codex-primary-runtime\dependencies\native\poppler\Library\bin` 加入 `PATH`，供 `pdfinfo.exe` 和 `pdftoppm.exe` 使用。
- 中文路径异常时，先复制到任务内的纯英文临时路径再转换。
- `dep-*.d` 或 `Could not find platform independent libraries <prefix>` 警告可能不影响输出；以 PDF/PNG 是否存在、非空且可正常打开为成功标准。
