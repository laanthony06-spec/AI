# 远程触发语句库

## 使用原则

远程触发语句用于手机、飞书、微信、快捷指令或后续 Agent 助理入口。  
所有触发都应明确：

1. 输入范围
2. 输出位置
3. 是否允许改文件
4. 是否需要人工确认

## Ask 模式：只分析，不改文件

- 帮我分析今天新增的原始资料，但不要改文件。
- 看一下最近的 AI Agent 简报，有哪些值得借鉴？
- 检查 WaferBalance 相关笔记，有没有明显缺口？
- 总结最近一周自动派工资料的新增知识。

## Plan 模式：生成计划，等待确认

- 为今天新增的需求单图片生成处理计划，先不要执行。
- 检查 `00.raw-materials`，列出需要 OCR / 结构化 / 提纯的资料。
- 根据最新 AI 情报，提出可落地任务队列，先给我确认。
- 为自动派工知识库设计一次整理计划，列出会改哪些文件。

## Craft 模式：授权范围内自动执行

- 处理今天新增原始资料，完成 OCR、结构化和索引刷新。
- 生成本周 AI Agent 简报，并更新 Dashboard。
- 从新增需求单中提取派工规则，生成 Evidence 和 TestCase 草案。
- 刷新 Agent Knowledge Ops 索引，并检查是否有乱码。
- 运行敏感信息扫描，生成脱敏报告。

## 自动派工专项触发

- 从新增需求单图片中提取 DSP 派工规则。
- 整理 WIP / Queue Time 相关知识，更新规则卡片。
- 为 WaferBalance 生成更多边界 TestCase。
- 检查 AMHS / MES / AI Scheduling 相关简报是否有可落地方案。

## 安全触发

- 扫描仓库是否存在 Token、Cookie、Secret，并生成脱敏报告。
- 检查 `.gitignore` 是否覆盖 `.env`、`.venv` 和日志文件。
- 检查是否有不应提交到 GitHub 的敏感文件。

## 发布前触发

- 把这篇 Obsidian 笔记转成公众号草稿检查清单。
- 把这篇 Obsidian 笔记转成 X Article 版本。
- 检查这篇文章是否包含不应公开的敏感信息。
- 发布前只生成检查报告，不要自动发布。

## 禁止自动执行的动作

- 不自动群发公众号。
- 不自动发布 X Article。
- 不自动提交账号密钥。
- 不自动删除大量文件。
- 不自动修改第三方平台账号权限。
